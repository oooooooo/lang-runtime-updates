How to read this

High or above is the "apply now" signal. Medium and low fixes can often wait for the next scheduled update if you don't use the affected feature.

Scores depend on who rated the CVE. Microsoft often rates denial-of-service bugs as 7.5 (High), Oracle scores Java conservatively, and Go CVEs are scored by NVD or CISA because the Go team doesn't publish scores.

Go's standard library includes HTTP, TLS and templates, which other languages leave to third-party packages. Rust fixes ship only in the latest version, which is backward-compatible.

Unknown means the official notes named no CVE, or the CVEs have no score yet.
